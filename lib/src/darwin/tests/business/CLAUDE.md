# The Business tests

**Mirror.** `tests/business/<module>/` tests `source/business/<module>/` ([ADR 0019](../../../../documentation/adrs/darwin/tests-live-in-the-layer-of-what-they-test.md)); a new module brings its test directory in the same change.

**Builds as:** one Swift Testing target per module, `Business<Name>Tests`, depending on its module and its declared support; it may import its module's own edges and nothing in Presentation.

**Support:** `SupportSandbox` and `SupportDiscFixtures`, when a core test needs files; `SupportMIPS` (`tests/support/mips/`) — `MIPS`, a small R3000A assembler, and the registers by name, and the programs and images built from it that the PS1 console's and the session's tests share (`bytes`, `image(of:size:)`, `halt`, `printing`, `storing`); `SupportR3000ATrace` (`tests/support/r3000atrace/`) — `TraceKitTracer`, an R3000A tracer writing TraceKit's records, which brings TraceKit's files and diff with it. A core's tests build their programs and memory images in code — never a BIOS, never a game ([ADR 0013](../../../../documentation/adrs/darwin/shipped-code-derives-only-from-permissive-references.md) §6).

**Conventions:** hermetic — no network, files only inside a `Sandbox`, never the real home folder, never a real BIOS or game. `session`'s tests pace the session by `ManualClock` (`tests/business/session/Harness.swift`), a clock the test moves a sixtieth at a time, so its frames are exact and wait on no real time but one short test's, which holds `ContinuousClock`'s frames to at most 60 a second, with a loose floor a loaded machine still meets; every wait has a timeout, so no test hangs. `swift test` runs the debug configuration, where `PERSONAL_BUILD` gives the session the tracing console: the App Store build's `PS1Console` path is only compiled, by `swift build -c release` and the App Store archive, unless `swift test -c release -Xswiftc -enable-testing --filter BusinessSessionTests` is run by hand. Expected results come from psx-spx or a permissive reference's recorded trace, never a GPL emulator's source. A behavior spanning layers is tested here, in the highest layer it touches.

# Reference

The contracts iStation builds against and writes — today TraceKit's trace formats — one folder per platform. The [documentation router](../CLAUDE.md) says which application a change belongs to.

| Folder | Application |
|---|---|
| [`darwin/`](darwin/README.md) | **The Apple apps**, macOS (PS1 and PS2) and iOS (PS1), one Swift codebase; an item or note for one OS sits in its subfolder, `macos/` or `ios/` |
